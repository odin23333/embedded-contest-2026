# 播放界面反馈（已完成实板功能验收）

适用米联客 MLK-S200 / EG4D20EG176、TD 6.2.1。HDMI输出保持640×480。增加底部信息栏，范围x=8..631、y=394..435；右下角原实时时间戳仍位于y=440..467。

第一行示例：`PIC 1/4  NEXT 2/4  CACHE READY`。

- PIC为当前已经完整提交显示的图片序号/总数，不提前跳到仍在加载的图片。
- NEXT为下次顺序播放的图片；目录顺序与FAT32读取规则相同，不代表按文件名排序。单张图片显示NEXT -/-、CACHE N/A。
- CACHE WAIT表示尚未开始下一张预加载，LOAD表示正在读取/缩放/写缓存，READY表示下一张的源数据和DDR整帧写入均已完成。后台缓存READY不会自行切图。

第二行：

- 手动模式：`MANUAL  KEY1 NEXT  KEY2 AUTO`。
- 轮播模式：`AUTO 05S  KEY1 NEXT  KEY2 STOP`，依次5、4、3、2、1后发起换图。数值来自实际播放调度器计数，不另起一只估算计时器。等待按键请求、前台加载或暂停时不会显示虚假的继续倒计时。
- 请求尚在等待读图：`WAIT NEXT IMAGE - REQUEST QUEUED`。只保留原有的一次请求，不因多次按键累积跳图。
- 缓存就绪并正在渐变：`SWITCHING IMAGE - PLEASE WAIT`。
- 轮播暂时等候前台任务：`AUTO WAIT - IMAGE BUSY`。

信息栏只观察原控制状态，不修改切图、预加载、5秒轮播和应急逻辑。信息栏不随图片渐暗或可选亮度而变暗。进入应急时隐藏，错误恢复/FAULT时让出画面；KEY3退出应急或KEY6恢复并加载首图后自动显示。KEY1..KEY6、KEY16含义保持原样。

状态在每帧垂直消隐处快照；图像、DE/HS/VS一起增加一个像素时钟的输出寄存级，保持像素和同步对齐。图片缩放、FAT32、时钟、警报、静音和恢复功能均保留。

## 实板检查

1. 首图后应显示PIC 1/4，稍候CACHE由LOAD变READY；KEY1循环四张，编号与图片一致，下一张正确，渐变中有SWITCHING提示，画面无抖动或错行。
2. KEY2开启轮播，观察5→1倒计时和至少两次切图，KEY2停止后恢复MANUAL；时间戳继续递增，不被信息栏遮挡。
3. KEY3进入应急，信息栏隐藏、中文/闪烁/警报正常；KEY4静音恢复、KEY3退出后信息栏和时间恢复。KEY6重试期间隐藏播放栏，首图加载后重新显示。
4. 可选检查：无卡KEY6后原E41及恢复提示仍正常；插回原卡KEY6后编号从首图重新开始。

离线渲染和仿真不能代替实板检查。此候选不写Flash，不代表已完成长期稳定性验收。上一已实测错误恢复固件保留为回退。
