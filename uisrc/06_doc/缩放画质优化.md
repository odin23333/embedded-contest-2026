# 缩放画质优化（已完成实板功能验收）

平台为米联客MLK-S200 / EG4D20EG176，TD6.2.1。HDMI输出仍为640×480；BMP格式、FAT32读取、等比例居中和黑边规则不变。

默认缩放由最近邻替换为中心对齐双线性插值。每个输出点使用相邻两行、两列源像素，横向插值后再纵向插值。权重为Q0.8定点，每级四舍五入；边缘夹到最近有效像素。640×480原尺寸的权重为零，像素保持一致，不会引入整体偏移或边缘模糊。

双线性插值主要改善放大时的台阶、斜线和色彩跳变；缩小时也会混合相邻像素，但不属于完整面积滤波，强烈缩小时仍可能存在细纹混叠。它不能恢复源图已经丢失的文字或照片细节，不额外叠加锐化或修改素材。

采用两条2048像素源行缓存和复用的RGB插值运算，在后台读图阶段完成。完整输出帧仍写入原有DDR双缓冲，缓存READY、帧提交及渐变机制保持原样。此过程增加加载计算，快速连续切图或大图冷加载仍可能等待；不能把仿真时钟数称作实际TF加载时间。

保留QUALITY=0最近邻参数用于对照和回归；生产默认QUALITY=1，无需按键启用。

另将写FIFO的三周期生产者屏障改为由写时钟域内、保持至ACK的write_req启动，避开原屏障寄存器从存储时钟异步释放产生的removal路径。本地请求立即禁止生产者，FIFO清空信号被本地时钟采样并保持三周期释放屏障；ready再寄存一级，384/512字水位留下128字余量覆盖新增一级延迟。屏障覆盖ACK回传和厂商FIFO两周期释放；实际FIFO测试核对8次复位时机和4096个顺序数据字。FIFO清空/复位电平先经过两级写时钟同步，只对新增同步器第一级捕获设置例外；第二级、释放屏障、FIFO数据和DDR路径仍完整检查，时钟未放宽。

进度监测增加实际像素输出事件：从行RAM持续插值时，即使暂时没有SD扇区事件，也属于真实处理进度。短超时恢复测试已复现旧逻辑在第77877个像素误报停滞；此修复不延长看门狗时限，也不以busy电平充当进度。
