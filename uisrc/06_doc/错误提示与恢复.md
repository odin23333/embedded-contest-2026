# 错误提示与恢复（已完成实板功能验收）

目标平台：米联客 MLK-S200 / EG4D20EG176，TD 6.2.1。输出仍为 640×480。

出现故障时，保留最后一张完整图片（DDR失去就绪后旧图不可信，会隐藏），右上保留FAULT状态，图像上方新增错误码、原因和操作提示。首次故障原因保持到成功重试或KEY16复位，避免后续超时覆盖原始原因。错误提示每帧更新，应急中文画面优先，不被提示条遮挡。

## 使用方法

1. 检查并插好TF卡，文件使用FAT32、24位无压缩BMP（尺寸1..2048，底向上）；放入MLK_TEST文件夹，或在该文件夹不存在时放入根目录。
2. 按KEY6（第二排第二个）重新初始化读卡器、FAT目录和DDR图像缓存。此操作会清除当前缓存并重新加载首图，显示RETRYING；HDMI时钟、应急警报、静音/轮播偏好、RTC和校时串口不复位。
3. 首图完整写入并提交后错误码和RETRYING消失，可继续切图。重试仍失败则显示新的故障原因，修正后再次KEY6；不自动无限复位。
4. KEY16仍执行整机复位。正常状态也可KEY6主动重新扫描更换后的卡或文件；目录不会后台自动监测更新。

## 屏幕代码（E后为两位十六进制）

|代码|含义与处理|
|---|---|
|E02 / E03|扇区长度异常 / 扇区读取超时。检查接触、重插卡后KEY6。|
|E10..E13|启动签名、主分区、FAT32格式或布局不支持。检查FAT32卡及分区。|
|E14..E16|目录或FAT簇链损坏/超过读取范围。备份后在电脑检查文件系统。|
|E17|目录中没有可读取的BMP，检查MLK_TEST或根目录。|
|E20..E26|文件条目、文件长度或簇链异常，重新复制正确的BMP。|
|E30|BMP格式或尺寸不支持，改为24位BI_RGB、底向上、尺寸1..2048。|
|E41 / E81|初始化未完成或已检测到初始化状态丢失；检查TF卡后KEY6。不能仅凭此码断定硬件损坏。|
|E43 / E44|DDR就绪丢失 / 未就绪；KEY6重试，持续失败则检查供电并KEY16复位。|
|E45|读图/写缓存长时间无进展，检查卡后重试；该码不能精确区分卡响应停滞和DDR完成停滞。|
|E46|HDMI视频队列溢出，KEY6清除队列和图像链路后重新加载。|

板上未连接独立TF卡检测引脚：空闲时拔卡不保证立即报错，下一次实际读取或重新扫描时才会检测失败；换卡后应KEY6。仅支持当前规定的FAT32/BMP范围，不自动跳过坏图，不修改或修复卡内文件。

## 实板验收步骤

先确认四图、缩放、预加载渐变、轮播、时间戳均正常。无故障时KEY6应显示RETRYING并恢复首图。进入应急并静音后KEY6，应急闪烁/静音仍保持；恢复后退出应急图片与时间戳正常。取卡后KEY6，应出现读卡/初始化错误和重试提示；插回原卡再KEY6，应恢复首图并清除错误。最后重新检查KEY1..KEY4。

离线检查、重编译和时序通过不构成实板验收。当前已实测FAT32基线固件另行保留，历史W7_RC2/第八周冻结包不变。此版本尚未写Flash或完成长期运行验收。
